# ADITYA WAGH — Personal Story & Chronicle Portfolio

> **AI Engineer · Video Editor · Creative Technologist**  
> *"I don't create in one medium. I create across them."*

An interactive editorial short-film personal portfolio. Built with vanilla HTML5, custom CSS design systems, GSAP ScrollTrigger kinetic choreography, and Lenis smooth momentum scrolling.

---

## The Worlds

- **01 / THE VOID**: Monolithic typography, kinetic fragmentation, origin creed.
- **02 / THE HUMAN**: Luxury editorial magazine spread, core disciplines, dynamic role explorer, interactive philosophy manifesto.
- **03 / THE ENGINE**: Deep blueprint architecture, systems topology, neural RAG pipelines, technical stack cloud, case study schematics.
- **04 / THE CUT**: Darkroom film studio, analog timeline scrubber, anamorphic frame-by-frame stills, interactive before/after color grading slider, selected showreel archive.
- **05 / THE CREATOR**: Design studio / creative laboratory, kinetic discipline satellites, visual idea expansion diagram, thought-to-thing metamorphosis pipeline, multimedia pinboard, project constellation, creative process methodology, identity synthesis.

---

## Features

- **Persistent Editorial Header**: Adapts dynamic color palettes and typography according to the active world.
- **Direct Section Shortcuts**: Jump between worlds via desktop header links or mobile quick jump drawer.
- **Keyboard Shortcuts**: Press `1`, `2`, `3`, `4`, or `5` on the keyboard from anywhere on the page to glide directly to each world.
- **Micro-Interactions**: Custom red ink cursor with magnetic hover states, draggable color grade comparison, interactive playheads.
- **Performance & Accessibility**: GPU-accelerated transforms and opacity, mobile-first responsive layout (down to 360px), and support for `prefers-reduced-motion`.
